# BatchMyPhotos AI — Blur Detection Service

Local Python AI service for accurate blur detection using a fine-tuned MobileNetV3-Small CNN.

## Quick Start

### 1. Create virtual environment

```bash
cd ai-service
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

> **GPU support:** If you have an NVIDIA GPU, install the CUDA version of PyTorch:
> ```bash
> pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
> ```

### 3. Run the server

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at `http://localhost:8000`.

- Health check: `GET http://localhost:8000/health`
- Blur analysis: `POST http://localhost:8000/analyze`
- API docs: `http://localhost:8000/docs` (Swagger UI)

## Training a Model

### Step 1: Generate Synthetic Training Data

```bash
python training/generate_synthetic.py --input /path/to/sharp/photos --output data
```

This takes your sharp photos and generates blurry versions using Gaussian, motion, and defocus blur at varying strengths.

### Step 2: Prepare Dataset (if using raw labeled images)

```bash
python training/prepare_dataset.py --input /path/to/labeled/images --output data
```

Organizes images into `data/train/{blurry,sharp}/` and `data/val/{blurry,sharp}/` with an 80/20 split.

### Step 3: Train the Model

```bash
python training/train.py --data data --epochs 30
```

Training runs in two phases:
1. **Head-only** (10 epochs): Freeze backbone, train classifier head
2. **End-to-end** (20 epochs): Unfreeze all layers, fine-tune entire model

Best model saved to `models/best_model.pt`.

### Step 4: Evaluate

```bash
python training/evaluate.py --data data/val --model models/best_model.pt
```

Prints accuracy, precision, recall, F1, and confusion matrix.

**Target metrics:** >90% accuracy, >85% precision, >80% recall.

## API Reference

### `GET /health`

```json
{
  "status": "ok",
  "model_loaded": true,
  "device": "cuda"
}
```

### `POST /analyze`

**Request:**
```json
{
  "images": [
    { "baseName": "IMG_001", "data": "<base64-encoded-image>" },
    { "baseName": "IMG_002", "data": "<base64-encoded-image>" }
  ]
}
```

**Response:**
```json
{
  "results": {
    "IMG_001": { "score": 0.92, "isBlurry": true, "confidence": 0.92 },
    "IMG_002": { "score": 0.15, "isBlurry": false, "confidence": 0.85 }
  },
  "processedCount": 2,
  "elapsedMs": 45
}
```

- `score`: Probability of being blurry (0.0–1.0)
- `isBlurry`: `true` if score > 0.5
- `confidence`: Classification confidence (max of blurry/sharp probability)
- Max 20 images per request
